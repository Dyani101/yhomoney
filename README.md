# YhoMoney

YhoMoney is a lightweight, South African personal budgeting dashboard built with Vue 3, TypeScript, and Vite. The MVP focuses on monthly budgeting, simple comparisons, recurring commitments, and practical suggestions without authentication or AI integrations.

## Features

- Monthly budget cards and switching between months
- Add and remove budget entries with ZAR formatting
- Track income, expenses, remaining balance, and allocation percentage
- Compare the current month with the previous month
- View a basic budget activity timeline
- Store data locally in the browser with localStorage
- Responsive, calm interface designed for personal finance use

## Tech stack

- Vue 3
- TypeScript
- Vite
- CSS variables and custom design system

## Getting started

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Production build

```bash
npm run build
```

## Notes

- No login, no AI, and no bank sync are included in this MVP.
- This is intentionally a local-first budgeting tool designed around a monthly planning workflow.
